TELEPHOTE GUIDE · UPDATED 28 NOVEMBER 2026

Update Telephote inside the app

Telephote 0.3.1 and Android Test 0.3.1-android.2 include in-app updates. You can download a future matching release and restart into it without manually replacing a ZIP.

Try the 0.5.0 studio and microphone preview

The 0.5.0 release is a preview and is not offered by the regular stable updater. Download its complete ZIP, extract it into a new folder and open Telephote.exe. Keep your previous folder if you want to switch back. Phone audio needs companion build 7; the public iPhone download is still coming soon.

How to update stable releases

  1. Open Updates → Check for updates.
  2. If a newer version is available, choose Download. Telephote verifies the release and package before offering to restart.
  3. Finish your call, stop the camera and any recording, then choose Restart & update.

The app closes, replaces its portable folder and reopens. Your settings are kept. A previous-version folder is retained beside the app for recovery. The folder must be writable by your Windows account. There is no Windows installer or administrator prompt.

Already using 0.3.0 or an older build?

Download and extract a complete updater-enabled Windows ZIP once, then open Telephote.exe from the new folder. Older builds do not contain the update feature.

Separate update channels

The regular Windows app checks stable releases and skips previews. Version 0.3.1 remains the latest stable release. Telephote Android Test checks Android test releases. Updating does not move you between channels. Keep the two apps in separate folders and close the regular app before testing Android output in Teams.

Linux preview updates

Linux preview 0.5.0 does not yet have in-app updates. Download a later Linux archive, extract it into a new folder and run Start-Telephote.sh. Do not use a Windows ZIP with the Linux app. Linux downloads and requirements.

No subscription

The Windows app is free. The iPhone app costs A$5 AUD once. Telephote has no subscriptions or recurring fees. Third-party Android apps may have separate charges.

If an update cannot finish

The updater attempts to restore the previous folder if replacement or restart fails. For a power interruption or an interrupted recovery, close Telephote and use the retained previous folder. Downloading the complete ZIP again remains an alternative.
