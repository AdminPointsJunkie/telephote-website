TELEPHOTE GUIDE · UPDATED 26 NOVEMBER 2026

Download privacy

Telephote uses download statistics to understand usage of its Windows releases. Download analytics do not collect camera frames, recordings or microphone audio.

Public download counts

GitHub reports how many times each release ZIP has been downloaded. The displayed total adds those counts across regular and Android test releases. Updates, repeat downloads and automated downloads may count. This is not a count of unique people or proof that an app was installed or used.

Detailed download records

When a download goes through Telephote’s tracking service, the service can record the request time, IP address, approximate location supplied by the hosting network, selected platform/version, browser user agent and referring website origin. Location is approximate and can be wrong, especially with VPNs or proxies; it is not GPS. These records are private to the site owner.

Detailed records are retained for up to one year (365 days). Aggregate counts can be kept permanently. Direct GitHub downloads and in-app update downloads do not pass through the Telephote tracking service; GitHub does not provide their IP addresses or location records to Telephote. Historical IP/location records cannot be reconstructed from GitHub counts.

Current tracking coverage

The public download buttons currently link directly to GitHub. Detailed Telephote tracking is being prepared and is not active on these buttons yet.

Service providers

The main website uses GitHub Pages and the ZIP files use GitHub Releases. The separate statistics service uses OpenAI Sites and its Cloudflare infrastructure. These providers process requests under their own policies. GitHub privacy statement · OpenAI privacy policy · Cloudflare privacy policy.

Your camera video

The iPhone sends video directly to the Windows app over USB or encrypted local Wi-Fi. An Android app’s stream security depends on that app and protocol. Your meeting service handles the online call. Local recordings are saved on your PC.
