TELEPHOTE GUIDE · UPDATED 26 NOVEMBER 2026

Android webcam for Windows

Telephote’s separate Android test build receives a standard USB webcam or a local MJPEG camera stream. It runs from an extracted folder on Windows 11 x64, with no Windows installer and no Telephote subscription.

Using Linux? The Linux preview also accepts Android USB Webcam mode and compatible local MJPEG streams. The Windows instructions below use a separate executable and camera-output route.

Do I need an Android companion app?

Built-in USB Webcam mode: no. The phone supplies a standard webcam connection. Network streaming: yes. Use a compatible Android camera app, such as IP Webcam or DroidCam Classic. There is no Telephote Android companion in this release.

Option 1: Android over USB

  1. Connect a data-capable USB cable and select Webcam in the phone’s USB options.
  2. Extract the Android test ZIP and run Telephote.AndroidTest.exe.
  3. Select Android → USB webcam → Find USB cameras. Choose the phone and press Start camera.

The phone manufacturer must provide USB Webcam/UVC mode; the Android version alone does not guarantee it. File transfer or charging mode will not work. No ADB or new Windows driver is installed by Telephote. A standard USB webcam can also be selected directly in Teams.

Option 2: IP Webcam or DroidCam Classic

  1. Put the phone and PC on the same local network. Start the camera server in IP Webcam or the IP Cam feed in DroidCam Classic.
  2. In Telephote, select Android → Wi-Fi app and the matching preset.
  3. Enter the phone’s IP address and port shown by the app. Typical defaults are 8080 for IP Webcam and 4747 for DroidCam Classic; use the displayed value.
  4. If required, expand Sign-in and enter the camera server credentials. Then start the camera.

Custom MJPEG accepts a direct local HTTP(S) multipart JPEG stream address. It does not accept a web landing page, DNS hostname, public internet stream, RTSP or proprietary app protocol. DroidCam OBS and proprietary DroidCam USB transport are not supported. Third-party phone apps have their own prices and quality limits. Plain HTTP feeds are not encrypted; use only a trusted local network.

Use the picture in Teams

Close the regular Telephote app. Enable Use in Teams and other apps in the test build and select its camera output in Teams. Windows may name it AvStream Media Device. Keep using your headset or other microphone for audio. Work computer camera policies still apply.

Controls and test status

Windows picture adjustments, digital zoom, rotation, pause, snapshots and recording use the shared Telephote pipeline. Choose optical lenses, focus, background effects and automatic framing in the phone app: remote Android controls for those features are not implemented.

Automated checks cover USB frame handling and a synthetic local MJPEG stream. Physical Android capture, third-party app interoperability and Android-to-Teams calls still need hardware testing. This is a separate test release, not a promise of compatibility with every Android phone or webcam app.
